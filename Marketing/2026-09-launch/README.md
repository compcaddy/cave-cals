## Suggested first choice

Use **Food simple. Tracking simple.** as the brand introduction, followed by the actual Quick Add breakfast demo. Use **Say it. Log it.** for a separate voice demonstration so viewers see the estimate-review step. Keep the routine concept for a later post instead of launching all messages at once.

Advertise onboarding/macros only after that native build is publicly available. Creative performance is untested; no installs, revenue, endorsements, or weight-loss results are promised.
